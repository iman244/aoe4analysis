## Scope

- **In:** A dashboard builder for a **single game (match)**: build a dashboard from charts and other data views, save it, share it, browse other people's dashboards, and open any game through any dashboard.
- **Out (for now):** Dashboards for players, civilizations and maps, and for groups of games. Analysis of a player's games is a later phase.
