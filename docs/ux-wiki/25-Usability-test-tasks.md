## Inputs

Check each input is done and linked before you start.

- [ ] **[#6 Analytics and support-ticket review](06-Analytics-and-support-ticket-review)**
  - **Why it's needed:** Analytics show what happens, and tests explain why, so test tasks should target those problem areas.
  - **How it's used:** Problems found in analytics are investigated in usability tests.
  - **Reference:** [3 Uses for Analytics in UX Practice](https://www.nngroup.com/articles/analytics-user-experience/) (NN/g states this)
- [ ] **[#9 Personas](09-Personas)**
  - **Why it's needed:** Test participants must represent the real target users.
  - **How it's used:** Persona traits become screening criteria for test participants.
  - **Reference:** [Personas Make Users Memorable](https://www.nngroup.com/articles/persona/) (NN/g states this)
- [ ] **[#12 Problem statement / How Might We](12-Problem-statement-How-Might-We)**
  - **Why it's needed:** Test tasks must check whether the design solves the stated problem.
  - **How it's used:** Defines what the test must prove.
  - **Reference:** [Task Scenarios for Usability Testing](https://www.nngroup.com/articles/task-scenarios-usability-testing/)
- [ ] **[#13 UX success metrics](13-UX-success-metrics)**
  - **Why it's needed:** Tests need defined measures to judge pass or fail.
  - **How it's used:** Sets what to measure in tests: task success, time on task.
  - **Reference:** [Usability Metrics](https://www.nngroup.com/articles/usability-metrics/) (NN/g states this)
- [ ] **[#16 User flows and task flows](16-User-flows-and-task-flows)**
  - **Why it's needed:** Tasks should cover the flows that matter most.
  - **How it's used:** Test tasks come from the key flows.
  - **Reference:** [Task Scenarios for Usability Testing](https://www.nngroup.com/articles/task-scenarios-usability-testing/)
- [ ] **[#21 Paper sketches](21-Paper-sketches)**
  - **Why it's needed:** Early tests need something cheap that users can react to.
  - **How it's used:** Paper prototypes are tested with users early.
  - **Reference:** [Paper Prototyping](https://www.nngroup.com/articles/paper-prototyping/) (NN/g states this)
- [ ] **[#23 Clickable prototype](23-Clickable-prototype)**
  - **Why it's needed:** Usability tests need an interactive design for users to try.
  - **How it's used:** The prototype is what users test.
  - **Reference:** [UX Prototypes: Low vs. High Fidelity](https://www.nngroup.com/articles/ux-prototype-hi-lo-fidelity/) (NN/g states this)
